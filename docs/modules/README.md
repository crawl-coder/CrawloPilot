# modules/ 模块文档

本目录按**业务链路**组织 CrawloPilot 的功能模块文档，从用户进入平台到任务完成。

## 阅读顺序（业务链路）

```
进入平台 → 建项目 → 建爬虫 → 部署执行 → 分配节点 → 运行任务 → 查看结果
   │         │        │         │          │          │           │
  01-auth   02-projects  03-spiders   04-execution  05-nodes   06-tasks   06-tasks
```

| 序号 | 模块 | 说明 |
|------|------|------|
| [01](01-auth.md) | 认证与权限 | 登录、注册、JWT、RBAC 角色权限 |
| [02](02-projects.md) | 项目管理 | 项目 CRUD、文件管理、版本 |
| [03](03-spiders.md) | 爬虫管理 | 爬虫 CRUD、代码上传、Git、运行 |
| [04](04-execution.md) | 部署执行 | 四种执行器（Local/SSH/Docker/Agent）、任务生命周期 |
| [05](05-nodes.md) | 节点管理 | 服务器 × 执行通道模型、节点 CRUD |
| [06](06-tasks.md) | 任务管理与实时日志 | 任务查询、状态、日志、WebSocket 推送 |
| [07](07-frontend.md) | 前端页面 | Vue3 页面结构与功能映射 |
| [08](08-testing.md) | 测试 | 测试体系与运行方式 |

## 与其他目录的关联

- **实现依据**：各模块文档描述功能的**当前实现**（以代码为准）
- **设计说明**：专项设计在 [designs/](../designs/README.md)（如调度、服务器管理）
- **历史对照**：早期方案见 [legacy/](../legacy/README.md)（已过时，仅术语对照参考）

## 文档阅读约定

每个模块文档统一包含：**职责 → 数据模型 → 后端实现 → API → 前端 → 已知限制**。
若某模块与设计文档有出入，以模块文档（当前实现）为准。
