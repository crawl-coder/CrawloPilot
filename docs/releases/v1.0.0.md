# CrawloPilot v1.0.0

> 发布日期：2026-08-07

首个正式版本。V1 聚焦「爬虫部署流程」：登录 → 项目 → 爬虫 → 代码 → 执行 →
状态/日志，全链路打通，并具备本地、SSH、Docker、Agent 四种执行方式与定时调度能力。

## ✨ 新特性

**认证与权限**

- JWT + RBAC：用户 / 角色 / 团队 / 权限码四级模型
- 用户管理（`/users`）后端 admin 鉴权

**项目与爬虫管理**

- 项目 CRUD、版本管理、代码文件上传与在线编辑
- 爬虫 CRUD、代码文件树 / Monaco 编辑器、运行与停止
- 代码来源三种方式：Git 仓库克隆（保留完整 `.git`）/ ZIP·TAR 上传 / 空模板
- Git 工作流：提交 / 推送 / 拉取 / 切换分支，凭据单次注入不落盘
- Git 凭据体系：个人凭据（Fernet 加密、创建爬虫自动填充）+
  团队机器人凭据池（admin 维护、轮换一处生效）

**任务执行**

- 四种执行模式，统一执行器契约，按 `deploy_mode` 分发：
  - 本地进程（LocalExecutor，无需 Docker/Celery）
  - SSH 远程节点（SshExecutor）
  - Docker 直连节点（DockerExecutor，基础镜像复用 + 任务镜像秒级构建）
  - Agent 节点（`agent/crawlo_agent.py`，反向注册 / 心跳 / 任务领取 / 日志回报 / 停止指令）
- Server 实体：真实服务器管理，服务器下创建 SSH / Docker / Agent 三种执行通道
- 任务全生命周期：状态机、实时日志（WebSocket 推送）、暂停 / 恢复 / 停止 / 重试 / 删除
- 运行统计：自动解析爬虫指标（pages / items / errors）回写运行记录

**定时调度**

- 进程内 APScheduler 3.10，不引入 Celery，控制面无额外依赖
- `schedule` 表驱动：cron / interval / once 三种触发方式
- 爬虫表单内配置入口，创建 / 更新 / 删除与调度注册三层生命周期同步
- 并发守卫、触发幂等、启停开关、立即执行、运行预览与历史
- 服务重启时从数据库重建全部调度任务

**其他**

- 仪表盘：项目 / 爬虫 / 任务 / 节点概览
- CI/CD：GitHub Actions 流水线（后端测试 / 前端测试 / 代码质量 / 安全扫描 / Docker 构建）
- 暗色模式与统一设计 Token 的现代化前端

## 🐛 关键修复

- 修复依赖冲突：`aiohttp` / `httpx` 版本与 crawlo 1.7.2 要求冲突导致依赖解析失败，
  已按 crawlo 要求放宽版本并补充 `email-validator` 等缺失依赖
- 升级被 GitHub 下架的过时 Actions（upload-artifact v3 → v4 等）
- 修复 docker-build 使用 secrets 的方式（secrets 不能直接写进 `if` 条件，
  改为映射到 job 级 env 判断，未配置 Docker Hub secrets 时自动跳过推送）
- `/users` 管理接口补全 admin 鉴权
- uvicorn 双监听问题根治

## ⚠️ 兼容性说明

- 运行环境：Python 3.10+、Node.js 18+、MySQL 8.0+、Redis
- 依赖的 crawlo 框架版本：1.7.2
- 全新数据库建库方式：使用 `Base.metadata.create_all` + `alembic stamp head`，
  不要直接 `alembic upgrade head`（早期裁剪移除的表仍被旧迁移引用）

## 📦 安装与升级

```bash
git clone git@github.com:crawl-coder/CrawloPilot.git
cd CrawloPilot
cp .env.example .env   # 按需修改数据库/Redis 地址
./start-dev.sh         # 初始化依赖与数据库，启动前后端
```

生产部署请参考根目录 [README](../README.md) 的「详细部署」章节。
