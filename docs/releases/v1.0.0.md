> 发布日期：2026-08-07

CrawloPilot 是 Crawlo 爬虫框架的配套管理部署平台。v1.0.0 为首次正式发布，
打通「登录 → 项目 → 爬虫 → 代码 → 执行 → 状态/日志」全链路，支持
本地 / SSH / Docker / Agent 四种执行方式与进程内定时调度。

## 🚀 新特性

### 认证与权限

- JWT + RBAC：用户 / 角色 / 团队 / 权限码四级权限模型
- 用户管理接口接入 admin 鉴权

### 项目管理

- 项目 CRUD 与版本管理
- 代码文件上传与在线编辑

### 爬虫管理

- 爬虫 CRUD、代码文件树与 Monaco 编辑器、运行与停止
- 代码来源三种方式：Git 仓库克隆（保留完整 `.git`）/ ZIP·TAR 上传 / 空模板
- Git 工作流：提交 / 推送 / 拉取 / 切换分支
- Git 凭据体系：个人凭据（Fernet 加密、创建爬虫自动填充）+
  团队机器人凭据池（admin 维护、一处轮换全局生效）

### 任务执行

- 四种执行模式，按 `deploy_mode` 分发：
  - 本地进程（LocalExecutor，无需 Docker/Celery）
  - SSH 远程节点（SshExecutor）
  - Docker 直连节点（DockerExecutor，基础镜像复用 + 任务镜像秒级构建）
  - Agent 节点（`agent/crawlo_agent.py`，反向注册 / 心跳 / 任务领取 / 日志回报 / 停止）
- Server 实体：真实服务器管理，服务器下创建 SSH / Docker / Agent 三种执行通道
- 任务全生命周期：状态机、实时日志（WebSocket 推送）、暂停 / 恢复 / 停止 / 重试 / 删除
- 运行统计：自动解析爬虫指标（pages / items / errors）并回写运行记录

### 定时调度

- 进程内 APScheduler 3.10，控制面无额外组件
- `schedule` 表驱动：cron / interval / once 三种触发方式
- 爬虫表单内配置，创建 / 更新 / 删除与调度注册三层生命周期同步
- 并发守卫、触发幂等、启停开关、立即执行、运行预览与历史
- 服务重启时从数据库重建全部调度任务

### 平台与体验

- 仪表盘：项目 / 爬虫 / 任务 / 节点概览
- CI/CD：GitHub Actions（后端测试 / 前端测试 / 代码质量 / 安全扫描 / Docker 构建）
- 现代化前端：暗色模式与统一设计 Token

## 🐛 Bug 修复

- 修复依赖冲突：`aiohttp` / `httpx` 版本与 crawlo 1.7.2 要求冲突导致依赖解析失败，
  按 crawlo 要求放宽版本并补充 `email-validator` 等缺失依赖
- 升级被 GitHub 下架的过时 Actions（upload-artifact v3 → v4 等）
- 修复 docker-build 使用 secrets 的方式（secrets 不能直接写进 `if` 条件，
  改为映射到 job 级 env 判断，未配置 Docker Hub secrets 时自动跳过推送）
- `/users` 管理接口补全 admin 鉴权
- 修复 uvicorn 双监听问题

## ⚠️ 注意事项

### 环境要求

- Python 3.10+、Node.js 18+、MySQL 8.0+
- 依赖的 crawlo 框架版本：1.7.2

### 数据库初始化

- 全新数据库使用 `Base.metadata.create_all` + `alembic stamp head` 建库，
  **不要直接 `alembic upgrade head`**（早期裁剪移除的表仍被旧迁移引用）

## 📦 安装

```bash
git clone git@github.com:crawl-coder/CrawloPilot.git
cd CrawloPilot
cp .env.example .env   # 按需修改数据库地址
./start-dev.sh         # 初始化依赖与数据库，启动前后端
```

生产部署请参考 [README](../../README.md) 的「详细部署」章节。
